AMOS

Automatic Medicine Ordering System

AMOS is an AI-powered platform designed to help patients manage long-term medications. It predicts medicine depletion, sends reminders, and automatically reorders medicines from nearby pharmacies to ensure uninterrupted treatment.

Key Features

AI Depletion Prediction

Predicts when medicines will run out based on dosage and quantity.

Automatic Reordering

Triggers refill orders before medicine stock runs out.

Nearby Pharmacy Detection

Identifies the nearest available pharmacy using location services.

Medicine Reminders

Sends daily notifications to remind users to take medicines.

Secure Payment

Ensures safe and reliable transactions through payment gateways.
